# Editorial Voice — governed elsewhere

The voice contract for this platform lives in two places, in order of
authority:

1. **`CLAUDE.md`** (repo root) — the operative rules: the two registers
   (long-form and short-form), the Forbidden Language list, punctuation
   mechanics, the structural moves, the Revision Pass, and the audience
   order (skeptics first, then doubting Christians, then pastors, then
   seekers).
2. **`docs/EDITORIAL-CONSTITUTION.md`** — the editorial mission every
   content decision nests under.

This file used to carry an early one-page sketch of the voice ("pastoral,
warm, intellectually serious") with a different audience ordering. That
sketch predates the constitution and the CLAUDE.md contract and is
superseded by both; the file remains only so existing links here don't
dangle. Do not add voice rules to this file — add them to `CLAUDE.md`.
