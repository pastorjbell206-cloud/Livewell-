# LiveWell Book Pipeline

> A menu, not a mandate. Nothing here is written yet and nothing is on the live
> site. This is the slate of books LiveWell should write, organized so each one
> is the destination of an article cluster that already exists on the site:
> the reader arrives through an essay, reads three more, and the book is the
> place all of it has been pointing.
>
> Governing test (from `docs/EDITORIAL-CONSTITUTION.md`): every book must help
> a Christian *live faithfully and wisely in a post-Christian America while
> recovering the depth, wisdom, practices, and imagination of historic
> Christianity.* If a title does not serve that, it is cut.
>
> Voice rules apply to every title, subtitle, and line below: no em-dash, no
> prose semicolon, no exclamation, none of the forbidden words. Premises are
> written in the Bell register on purpose, so the title already sounds like the
> book.

## How to use this

1. **Pick a pillar or a single title.** Priority should follow where the article
   traffic already is, so the funnel is real on day one.
2. **Premise first.** Before any book is written, its one-page premise gets
   written and approved, so a wrong direction is caught before the effort is
   spent.
3. **Then the funnel.** For the chosen book, the existing articles that should
   point to it get mapped and linked, so the book is the destination of a path
   readers are already on.
4. **Then write.** One excellent book over five rushed ones.
