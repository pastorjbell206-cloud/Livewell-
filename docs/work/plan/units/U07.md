# U07 History sources survey, corpus, and verifier

Card (MASTER-PLAN 10.6, with 7.2, 9.2): for every planned source in Parts 0
to VIII, a reachable public-domain text and its provenance, or "not
reachable"; fetch the texts the slice and Part I need into
`scripts/data/history-sources/` with `PROVENANCE.md`; write
`scripts/verify-sources.mjs` and add it to CI. Done when the survey is complete
and a seeded altered excerpt fails.

Surface: a script, its library, committed data, a test, one CI line. No
reader-facing page, no route, no API procedure, no schema.

## What changed

- **The corpus** (`scripts/data/history-sources/texts/`, 22 files, 3.1 MB).
  Every text the card names, plus the Part I texts the approved Rome pilot
  quotes: Pliny 10.96 and 10.97 (in full in McGiffert's note to Eusebius,
  *Church History* 3.33), the Martyrdom of Polycarp, Eusebius Books 3, 5, 6,
  7 and 8 (Lyon, Decius, Cornelius, the plague, the long peace), the Passion
  of Perpetua, Ambrose Letters 40, 41 and 51 (Callinicum, Thessalonica), the
  Creed and Synodal Letter of Nicaea, Athanasius's *De Decretis* and *On the
  Incarnation*, Augustine's *City of God* Book 5 (Theodosius's penance, 5.26),
  Theodoret Book 5 (Thessalonica), the Epistle to Diognetus, Justin's *First
  Apology*, Irenaeus *Against Heresies* Book 3, Tertullian's *Apology*,
  Origen *Against Celsus* Book 3, and Cyprian *On the Lapsed*. All ANF and
  NPNF translations (1885 to 1900) from the HistoricalChristianFaith
  Writings-Database, fetched on 2026-10-27 by raw URLs that name commit
  `328918aa7054fbcb2a8068e96b326a94a97345a2` (read from the clone an earlier
  run made in the scratchpad), stored byte for byte. No machine-translated
  Migne file is used. A per-folder `.gitattributes` keeps git from touching
  their line endings.
- **`manifest.json`**: per text, id, file, format, author, work, sections,
  translator, whether the file names the translator, how it was identified,
  edition, public-domain basis, origin (repository, commit, path, raw URL,
  date), sha256, bytes, and what notable passages it holds (each checked in
  the file).
- **`PROVENANCE.md`**: how the texts were fetched, what "identified" means,
  the public-domain basis, the quotation rules, the contract for U30 and U32,
  how to add a text, and a list of the texts generated from the manifest.
- **`SURVEY.md`** (see the deviation below): 136 planned sources across Parts
  0 to VIII, each Stored (22), Reachable with where (74), Reachable only in
  sixteenth- to eighteenth-century spelling (16), Not reachable (17), or In
  copyright (7). Parts I and II are covered almost entirely; Parts III to VI
  far better than the plan expected, through the Project Gutenberg mirror on
  GitHub and the Text Creation Partnership. An appendix gives the mirror path
  of every Gutenberg text cited.
- **`scripts/lib/history-sources.mjs`** and **`scripts/verify-sources.mjs`**:
  the gate. It fails when a stored text's sha256 or size differs from the
  manifest, a file sits in `texts/` unlisted, a manifest entry lacks any
  provenance field (or names a commit its URL does not pin), `PROVENANCE.md`
  has drifted from the manifest, or an excerpt in
  `client/public/history/sources/` or `client/public/history/sessions/` is not
  a normalized substring of the stored text it names (case, quotation-mark and
  dash style and spacing ignored; footnote numbers dropped; each note searched
  on its own; "...", "…" or "[...]" marks an omission whose pieces must appear
  in order in one passage, each at least eight characters). A source card
  (`type: "source"`) with no stored text fails. A failure names the file, the
  JSON path, the text, and how far the quotation agrees before it departs.
  `--write` regenerates the provenance list; file arguments check a draft;
  `--root` runs against another checkout. Two formats: the Writings-Database
  HTML (both its standard fragment and the older Word-exported pages) and
  plain text.
- **`server/history-sources.test.ts`** (14 tests): the gate passes as
  committed; the slice and Part I texts are present; real excerpts are found
  across footnote markers, endnote anchors and omissions; and seeded files
  fail: an altered Pliny excerpt ("thee" to "you"), a card with no stored
  text, a card naming a text not stored, a stored text edited by one word, an
  unlisted file, a manifest entry missing its translator or commit, and a
  stale `PROVENANCE.md`.
- **`.github/workflows/ci.yml`**: `node scripts/verify-sources.mjs` in the
  content-gates step.

## The contract for U30 and U32

`verify-sources.mjs` reads every JSON file under
`client/public/history/sources/` and `client/public/history/sessions/`. Any
object with an `"excerpt"` key (except a `"type": "scripture"` block, which is
U27's) and every `"type": "source"` card is checked against the stored text
named by its own `"corpus"` key or the nearest enclosing object's. U30 can
shape `sources/<id>.json` freely so long as excerpts use those two keys. The
registry's `sources.json` can carry the manifest's provenance fields by id.

## Not verified

- **Translators.** Only Tertullian's *Apology* names its translator in the
  file. The rest are identified from headings, editors' notes, a CCEL mirror
  comment, or a translator speaking in a note, and from the series' standard
  make-up; no scan of a printed volume could be reached. The manifest and
  `PROVENANCE.md` say so per text. *De Decretis* is left without a named
  translator.
- **Pins outside the Writings-Database.** No commit id could be read for the
  Text Creation Partnership or Gutenberg mirror repositories (no API); a text
  from them is pinned by sha256 when stored. The Perseus and Creeds.json
  commits come from earlier scratchpad clones.
- **TCP terms** for texts its index marks "Restricted" (Helwys, the 1646
  London Confession, Luther's 1579 *Liberty*): not confirmed.
- Several survey rows say "confirm before use" (the Aristides, Nestorius,
  Severus, Columba and Pascal translators; whether Wesley's 1795 journal
  extract reaches May 1738). These are marked in the survey.
- `pnpm build`, the sitemap, prerender and canonical audit were not run: no
  UI, route or build script changed. `pnpm exec tsx scripts/validate-catalogue.mjs`
  and `build-search-index.mjs --check` were not run (nothing they read
  changed). The CI run itself has not been seen; everything above was run
  locally.
- Two web searches were used (to learn where the Gutenberg mirror's repository
  list is kept); the list itself came from the `gitberg` package on PyPI. A
  probe of other package mirrors was refused by the session's permission check
  and was not pursued.
