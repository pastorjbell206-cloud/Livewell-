- **`--` throughout the Parenting Stage Guide.** The card names "Ages 1--3",
  which is fixed, but the guide's body carries 56 ` -- ` dash stand-ins and its
  own SEO title reads "Parenting Stage Guide -- Age-Specific ...". Eight tool

  That is the shared component, used site-wide; it meets the 24 px WCAG 2.5.8
  minimum but not the plan's 44 px target (9.7). Not changed here (blast
  radius); U14 or U34 can take it. Its copy also carries an em-dash ("most
  likely — not your device"), shared and pre-existing.

  Scripture; the gate also exempts any span in curly or straight double
  quotes anywhere in a family file. Reasonable (a quotation keeps its own
  punctuation), but invented dialogue inside quotes would pass.

  `{ younger, older, together? }` (5.2), but `FamilyDevotions.tsx`'s shape
  guard requires an array, so one banded devotion would turn the whole page
  into `LoadFailed`. Not a bug today (no banded data); U21 must change the page
  and the guard in the same PR as the first banded devotion.
- **Devotions page loads all three files or none.** A failed seasonal file now
  hides the weekly list too (before, it degraded silently). Acceptable with a
  retry; noted for U13/U17.
