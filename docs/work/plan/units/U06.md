# U06 Cleanup that needs no decision

nine stale tool descriptions and Which Lens's ending; one-hop redirects with
`redirectTo` stubs for the six crisis landings, `/for-families`, `/parenting`
and `/marriage`; re-point redirects that land on `/parenting`; re-point the

  sentence removed, nothing added.
