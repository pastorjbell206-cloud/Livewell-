# Study guides, share g2b: ledger of claims checked

Every quotation of a person (other than Scripture), every book, date and biographical claim the old guides carried that I kept, changed or cut. "Known" means a widely documented fact I did not search and judged safe; an editor may want to spot-check these. "Searched" means a web search run on 2026-11-18. Scripture is quoted from the ESV, the text these guides already used; it was checked from memory, not machine-checked (there is no ESV in the repository).
