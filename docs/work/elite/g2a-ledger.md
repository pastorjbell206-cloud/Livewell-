# Study guides, share g2a: ledger of claims checked

Every quotation of a person other than Scripture, every book, date and biographical claim the old guides carried, and what happened to it. "Searched" means a web search I ran on 2026-11-18. "Known" means a widely documented fact I did not search and judged safe; an editor may want to spot-check these. Scripture is the ESV, which these guides already used; it was quoted from memory of the ESV (there is no ESV in the repository), so it was not machine-checked.
