# The Quality Gate — nothing ships until it passes

The standard everything on this site must meet before it goes live. Run any
asset against this gate and answer plainly: **SHIPS** or **GOES BACK** — and
if it goes back, exactly what is short. The gate is pass/fail on every line;
"mostly" is a fail.

---

## For written content (essays, sermons, guides, books, doctrine, domains)

1. **The one-question test.** Could this have been written by any competent
   pastor, or only by Bell? If the honest answer is "any competent pastor,"
   it goes back. The biography (atheism to faith, the absent father, five
   sons, the small-town pastorate) is load-bearing or absent — never
   decorative.
2. **Zero kill-list violations.** No forbidden words, forbidden phrases,
   therapy-speak, signposting, banned openers. No exclamation marks outside
   verbatim quoted Scripture. Run the literal scan; zero means zero.
3. **Scholarship is load-bearing and verified.** Every named scholar is
   engaged (what they actually argued, in plain words) or cut. Every date,
   council, study, and quotation is real and checked. A citation that cannot
   be verified is removed, never invented. Remove the name from the sentence:
   if the sentence still says the same thing, the name was decoration.
4. **Scripture is verbatim, ESV unless a translation choice is doing named
   work,** with the reference traveling with the quote — and at least one
   passage unfolded, not proof-texted, where the piece leans on the text.
5. **Contested ground gets the steelman.** Each position stated in its
   strongest voice — the reader should not be able to tell where the author
   lands from the steelman alone. The disagreement is ordered
   (first/second/third) before it is argued. The guardrail fires in both
   political directions or the piece goes back.
6. **The three movements are present.** Symptom → cause → wisdom. A piece
   that stops at the symptom is journalism; at the cause, a lecture. Neither
   ships.
7. **Self-implication is real.** The writer is inside the indictment. Where
   the piece points only at "them," it goes back.
8. **The ending leaves weight.** A verdict, not a summary. No bow that undoes
   the piece's own weight. No doubled last line faking gravity.
9. **It says something that exists nowhere else.** If the reader could get
   this from any decent blog on the topic, it is not done.
10. **Crisis-adjacent content keeps a path to real help** and never
    diagnoses, never validates despair, never details self-harm.

## For tools and instruments

11. **The output changes substantively with the input.** An if-chain over
    canned blobs is not a tool and does not ship as one.
12. **Flawless on a phone.** Every screen, every state, thumb-reachable,
    nothing overflows.
13. **Every edge state is handled.** Empty input, wrong input, zero results,
    slow connection, revisit-with-saved-data. An error always gives a way
    forward, never a dead screen.
14. **A non-technical person succeeds on the first try.** Purpose obvious in
    seconds, instructions plain, no jargon.
15. **The result is worth keeping.** Saved, printable, or shareable — and
    returning to the tool respects what the user did before.
16. **The uncopyable element is present.** The feedback prose, the corpus
    connection, the pastoral read — the thing a competitor with a form
    builder cannot clone. All copy in-voice and kill-list clean.

## For everything

17. **CI is green** — typecheck, content validators, tests, build — and the
    change was verified on a preview, not assumed.
18. **Both runtimes** if it touches the API; token discipline if it touches
    the UI (no hardcoded hex, palette rules hold).
19. **It was read aloud** (content) or **used on a real phone** (tools) by
    the person shipping it. The ear catches what the eye forgives.

---

## Applying the gate

For any asset: walk the numbered lines in order and mark each PASS or FAIL
with one line of evidence. The first FAIL stops the walk — report **GOES
BACK** with the failing line numbers and exactly what is short. Only a clean
sheet reports **SHIPS**.
