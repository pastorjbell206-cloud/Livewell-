Rewritten essays live here as `<slug>.json` ({ slug, title, excerpt, body (Markdown), updated }), one per shelf essay; after adding one, run `node scripts/build-essays-index.mjs`.

Then run `node scripts/validate-essays.mjs` (a CI gate). It holds every file to the shape above and to the house rules: no Forbidden Language and no rulebook leakage ("steelman," "verdict," "indictment," "self-implication," "both-sidesism") in our own prose; no em-dash in our own prose ("---", "--", and a spaced en-dash count too), and none at all in the title or excerpt; an exclamation point only inside quoted Scripture with its reference beside it; internal links only to public pages, never through a redirect; at least one Scripture reference; sections under `##`, since the page sets the title as the only H1; and Closing Texts written as *"Quote."* (Reference) on one line. A quotation, in double quotation marks or a `>` block quote, keeps its own words and punctuation.
